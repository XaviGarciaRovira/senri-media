# senri-media

Vídeos i portades de les xarxes de [Senri](https://senri-kappa.vercel.app) (@senriapp), publicats aquí perquè Metricool els pugui programar.

- `videos/AAAA-MM-DD-tema.mp4` i la seva portada `.jpg`.
- `guions/`: el guió JSON de cada vídeo.
- `calendari.md`: què s'ha publicat i el pla vigent.
- `tools/senri-shorts/`: l'eina que genera els vídeos (skill senri-shorts).

Música original generada per a Senri. Traços dels kanji: [KanjiVG](https://kanjivg.tagaini.net/) (CC BY-SA 3.0). Tipografies: SIL Open Font License (vegeu `tools/senri-shorts/assets/fonts`).
